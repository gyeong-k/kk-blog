# 경로는 문자열

## req.url은 문자열일까?
- 문자열이다!
- 형태 : req.url = "/"
- /, /todos, /users/1 같은 건 주소(path) 이고, 주소는 본질적으로 문자열
- http://localhost:4000/todos
  - http → 통신 방식(프로토콜)
  - localhost → 어느 컴퓨터인지
  - 4000 → 어느 포트인지
  - /todos → 어떤 경로(path)인지
 
## 왜 문자열이 중요할끼?
- 서버는 문자열 비교로 분기
- 예
  - /
  - /todos
  - /users
 
## 중요 개념
- 모듈 → require("http")
- 요청 → req
- 응답 → res
