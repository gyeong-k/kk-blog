# 간단하게 코드 만들기

1. 서버기능 가져오기
    - 서버 만들 도구 : require
    - require("http") : 뭘 가져오지?

2. 요청이 오면 어떻게 응답할지 정하기
    - 브자우저 접속 -> 요청(request) -> 서버가 응답(response)
      - createServer(...) : 요청이 오면 뭘하지?, 서버 객체 만들기
    - 응답 : "hello" 텍스트
      - res.end(...)

3. 포트 열고 실행
    - 3000 포트 열고 실행
      - listen(3000, ...) : 어디서 기다리지?

- 작성한 코드를 실행 후 http://localhost:3000 접속 -> hello 표사

- listen : 서버 시작될 떼 실행 -> 그 후, 브라우저 요청 들어옴
