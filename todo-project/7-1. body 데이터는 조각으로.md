# 한 번의 요청, 여러개 body 조각
- 한 번의 요청 안에서도, 네트워크에서는 body가 나눠져 들어올 수 있음
  - 편지 봉투 안 종이가 여러 장으로 나눠져 들어온다
 
## req
- 하나의 값 X
- 요청 데이터가 흘러들어오는 통로(stream)
  - 조금씩 들어올 수 있다
- req.on(...)
  - 데이터가 도착했을 때 뭘 할지

요청으로 온 데이터 조각 -> 임시 배열에 담아 -> 문자열로 결합

POST /todos 요청이 오면:

1. 조각을 담을 배열을 만든다
2. 데이터 조각이 오면 배열에 넣는다
3. 끝나면 조각들을 합쳐 하나의 문자열로 만든다
4. 그 문자열을 todoList에 추가한다
5. 응답을 보낸다

“입력 → 처리 → 저장 → 응답"

- trim()
  - 들어온 데이터를 그대로 믿지 않는다
  - 앞뒤 공백과 줄바꿈을 정리
  - 빈 문자열이면 추가 X
 
- join()
  - 배열 -> 하나의 문자열로
  - [배열].join("") : "" = 배열 요소 사이 아무것도 넣지 않고 붙임
 
##흐름
- body 조각 받기
- 배열에 저장
- join("")
- trim()
- 비어 있지 않으면 todoList에 추가
- 응답 보내기
