# node.js 를 이용해 간단 서버만들기

## node와 npm
- node: 자바스크립트를 컴퓨터에서 실행하는 도구
  - 내 mac에서 프로그램처럼 실행
- npm : Node.js에서 사용하는 자바스크립트 패키지(라이브러리/모듈)를 관리하는 도구
- 설치 확인
  - node -v
  - npm -v

## 파일 만들고 편집모드로
- touch server.js
  - touch 파일이름 : 빈 파일 생성
- Mac 명령어 : open
  - open -a "[앱이름]" [파일명]
    - 예시) open -a Visual\ Studio\ Code server.js
