# 서버는 무엇을 보고 응답을 결정하는가
GET /todos
- method, url 중 어떤 값을 보고 분기?
  - 분기 : 조건에 따라 다른 코드로 나뉘어 실행되는 것 = 길이 갈라지는 것

## 둘 다 봐^^
- 같은 /todos 경로라도 의미 달라
  - GET /todos → 목록 조회
  - POST /todos → 새 투두 추가

- (장소) 어디로 왔는지 → url
- (행동) 무슨 행동을 원하는지 → method

## POST가 따로 필요? O
- 투두를 추가하는 건 “조회”가 아니라 서버 상태를 바꾸는 행동
- 단순히 주소창에 /todos를 입력하는 건 대체로: GET
