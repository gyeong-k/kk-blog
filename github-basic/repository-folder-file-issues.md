# repository, file, issues 의 차이

## repository

- 저장소, 가장 큰 단위
- 이 안에 폴더와 파일을 넣을 수 있음

## folder

- 주제별 묶는 용도
- 만드는 법
  - repository 안 [add file] 버튼 -> [Create new file] -> 맨위 [Name your file]
  - /폴더이름/폴더이름/파일이름

  
## file

- 실제 글을 쓰는 공간으로 .md 확장자


## issues

- 체크 리스트, 메모장
- 작업 메모, 할 일, 버그 기록
